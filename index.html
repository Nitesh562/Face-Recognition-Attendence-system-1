Appendix: 12 Sample Viva Voce Questions & Answers

12 Q&A
Q1. What is face recognition?

Biometric computer vision technique that identifies or verifies a person from digital images/video by comparing facial features with an enrolled dataset.

Q2. What is Haar Cascade?

An object-detection algorithm proposed by Viola and Jones that uses rectangular Haar-like features evaluated via integral images and cascaded classifiers.

Q3. What is OpenCV?

Open-source computer vision library providing image processing, real-time video capture, filtering, feature extraction, and ML classifier tools.

Q4. Why convert images to grayscale?

Converts 3-channel color data to 1 intensity channel, cutting processing overhead by 66% while preserving spatial and edge geometry.

Q5. What is a cascade classifier?

Multi-stage rejection architecture where non-face background windows are discarded in early stages, speeding up processing to 30 FPS.

Q6. What is AdaBoost?

Adaptive Boosting machine learning algorithm that selects the best weak rectangular features from thousands and combines them into a strong classifier.

Q7. Why is duplicate attendance check required?

Live video captures 30 frames per second. Without a duplicate check, a student would be marked 30 times in 1 second. It enforces 1 record per student per day.

Q8. What is the role of MySQL?

Provides persistent relational storage for student identities and attendance timestamps, ensuring data integrity and queryable history.

Q9. What is Tkinter?

Python standard desktop graphical toolkit used to create forms, buttons, canvas video display, and administration dialogs.

Q10. Limitations of face recognition?

Dim lighting, extreme head pose (>45 degrees), partial occlusions (masks/glasses), and 2D photo spoofing without liveness checks.

Q11. How can the system be improved?

Deep CNN embeddings (FaceNet/ArcFace), active liveness detection, cloud synchronization, and automated parent SMS notifications.

Q12. Detection vs Recognition?

Detection locates if and where a face exists in a frame (Haar Cascade). Recognition determines who that specific face belongs to (LBPH).
